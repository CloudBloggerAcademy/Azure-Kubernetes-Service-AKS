# Kubernetes – Introduction, History & Deployment Notes

## 1. Who Created Kubernetes?

Kubernetes was originally created by engineers at **Google**.

Google engineers used their experience with large-scale container orchestration systems such as **Borg** and **Omega** to design Kubernetes.

### Key Points

- Kubernetes was created by **Google engineers**.
- Kubernetes was introduced as an **open-source project in 2014**.
- Its design was inspired by Google's experience with **Borg and Omega**.
- Kubernetes became part of the **Cloud Native Computing Foundation (CNCF)** ecosystem.
- Today, Kubernetes is developed as an **open-source, community-driven project**.

> **Simple Meaning:**  
> Google created Kubernetes → Kubernetes became open source → CNCF became its home → Today, the global community contributes to Kubernetes.

---

## 2. Kubernetes Timeline

### 2014 → Kubernetes Created

Google engineers created Kubernetes based on their experience managing containers and large-scale applications.

### Google → Large-Scale Experience

Google had experience running huge services such as:

- Google Search
- YouTube
- Gmail
- Other large-scale applications

This experience influenced the development of Kubernetes.

### CNCF → Open-Source Community

Kubernetes became part of the CNCF ecosystem, helping it grow as a community-driven open-source project.

### Today → Runs Everywhere

Kubernetes can run across:

- Public Cloud
- Private Cloud
- On-Premises Datacenters
- Physical Servers
- Hybrid Cloud
- Multi-Cloud Environments

## 3. Kubernetes Services by Cloud Providers

Major cloud providers offer **managed Kubernetes services**.

| Cloud Provider | Kubernetes Service |
|---|---|
| **AWS** | Amazon EKS – Elastic Kubernetes Service |
| **Microsoft Azure** | Azure AKS – Azure Kubernetes Service |
| **Google Cloud** | GKE – Google Kubernetes Engine |
| **Oracle Cloud** | OKE – Oracle Kubernetes Engine |

### Why Managed Kubernetes?

Managed Kubernetes services reduce the operational effort involved in:

- Control-plane management
- Kubernetes upgrades
- High availability
- Infrastructure management
- Security and maintenance

## 4. Kubernetes on Public Clouds

Kubernetes can be deployed on major public cloud platforms:

1. **Microsoft Azure**
2. **Amazon Web Services (AWS)**
3. **Google Cloud Platform (GCP)**
4. **Oracle Cloud Infrastructure (OCI)**

### Quick Reference


## 5. Kubernetes on Private Cloud & On-Premises

Kubernetes is not limited to public clouds.

Organizations can run Kubernetes in their own private cloud or datacenter environments.

### Common Infrastructure

- **VMware**
- **Nutanix**
- **Microsoft Hyper-V**
- **Physical Servers / Bare Metal**

### Example

```text
Private Cloud / On-Premises
            ↓
 VMware / Nutanix / Hyper-V
            ↓
    Kubernetes Cluster
            ↓
     Applications
```
